# SPMS Admin Demo

## Cách chạy

```bash
cd spms_demo
npm install
npm start
```

Sau đó mở trình duyệt:

```text
http://localhost:3000
```

## Tài khoản demo

Bấm nút **Đăng nhập qua HCMUT_SSO** là vào thẳng trang Admin.
